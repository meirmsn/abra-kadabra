# Spec: lint-staged-rename-symlink

**Sources:**

- `kit/TODOS.md` § lint-staged stash backup chokes on rename + new-symlink-at-old-path — primary scope
- `PLAN.md` row `lint-staged-rename-symlink` — scope summary and source pointer
- Prior spec `specs/sync-show-first-confirm/spec.md` — style + structure reference

Fix the lint-staged stash backup failure when a single staging round combines a file rename with a new symlink at the old path. The `git stash` that lint-staged uses for backup chokes with `error: 'OLD/file' is beyond a symbolic link`. Disable the stash backup via `--no-stash` in both devshop and template pre-commit hooks.

### Headline (user-facing)

Pre-commit hooks no longer fail on rename-plus-symlink diffs — lint-staged's stash backup is disabled, unblocking squash-merge on these combos.

### Detail (team-facing)

Add `--no-stash` flag to `pnpm exec lint-staged` in both devshop and template pre-commit hooks. This disables lint-staged's `git stash` backup (the source of the `error: 'OLD/file' is beyond a symbolic link` failure on rename+new-symlink diffs). Side effect: also disables `hidePartiallyStaged` (acceptable — partial staging is uncommon). Bats convention test guards the flag against hook regeneration.

### D1: Fix strategy

**Decision:** `--no-stash` CLI flag on `pnpm exec lint-staged` (TODOS option 1).

**Rationale:** Minimal 1-line change per hook. The stash backup is a safety net for rolling back failed linter runs, but the devshop's linters are auto-fixers (eslint --fix, prettier --write) that rarely fail. Worst-case recovery on failure is `git checkout .`. Option 2 (custom wrapper replacing stash with patch backup) is cleaner long-term but costs more to build and maintain for a scenario that effectively never fires.

### D2: Scope — which hooks

**Decision:** Both devshop `.husky/pre-commit` AND `template/.husky/pre-commit`.

**Rationale:** Template propagates to new projects via sync. Devshop hook fixes the immediate blast radius. Existing projects pick up the change on next sync cycle.

### D3: `hidePartiallyStaged` side effect

**Decision:** Accept. `--no-stash` implies `hidePartiallyStaged: false` in lint-staged v15.

**Rationale:** Partial staging (staging individual hunks within a file) is rare in the devshop workflow — Claude commits with `git add` on specific files, not hunks. Full-file formatting is the common case.

### D4: Test coverage

**Decision:** Bats convention test verifying `--no-stash` presence in both hooks.

**Rationale:** Prevents regression if hooks are regenerated by husky or manually edited. A functional repro test (temp repo + rename+symlink scenario) is overkill for the safety gained — the root cause is well-understood (`git stash` + symlink = kernel-level ELOOP) and the fix is a config flag, not a code change.

### `kit/tests/convention-lint-staged-no-stash.bats`

```bats
#!/usr/bin/env bats
# Convention test: both pre-commit hooks must invoke lint-staged with --no-stash.
# Guards against regression if hooks are regenerated by husky or manually edited.

setup() {
  load helpers/setup
  DEVSHOP_ROOT="$(cd "$TESTS_DIR/../.." && pwd)"
  DEVSHOP_HOOK="$DEVSHOP_ROOT/.husky/pre-commit"
  TEMPLATE_HOOK="$DEVSHOP_ROOT/template/.husky/pre-commit"
}

@test "devshop .husky/pre-commit: lint-staged invoked with --no-stash" {
  [ -f "$DEVSHOP_HOOK" ] || skip "devshop pre-commit hook not found"
  run grep 'pnpm exec lint-staged' "$DEVSHOP_HOOK"
  assert_success
  assert_output --partial '--no-stash'
}

@test "template .husky/pre-commit: lint-staged invoked with --no-stash" {
  [ -f "$TEMPLATE_HOOK" ] || skip "template pre-commit hook not found"
  run grep 'pnpm exec lint-staged' "$TEMPLATE_HOOK"
  assert_success
  assert_output --partial '--no-stash'
}

@test "devshop .husky/pre-commit: lint-staged is not invoked without --no-stash" {
  [ -f "$DEVSHOP_HOOK" ] || skip "devshop pre-commit hook not found"
  # Ensure there is no bare `pnpm exec lint-staged` line (without --no-stash).
  # grep -P: the line must contain lint-staged but NOT --no-stash.
  run bash -c "grep 'pnpm exec lint-staged' '$DEVSHOP_HOOK' | grep -v -- '--no-stash'"
  assert_failure
}

@test "template .husky/pre-commit: lint-staged is not invoked without --no-stash" {
  [ -f "$TEMPLATE_HOOK" ] || skip "template pre-commit hook not found"
  run bash -c "grep 'pnpm exec lint-staged' '$TEMPLATE_HOOK' | grep -v -- '--no-stash'"
  assert_failure
}
```

**Test 1-2**: Positive — the grep for `pnpm exec lint-staged` returns a line containing `--no-stash`.

**Test 3-4**: Negative — no line contains `pnpm exec lint-staged` without `--no-stash`. Catches a scenario where someone adds a second lint-staged invocation without the flag.
