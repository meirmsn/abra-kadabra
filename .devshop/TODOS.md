Affects: `settings.json`, and potentially all other symlinked files (`.dcg.toml`, skill symlinks, commands). Evaluate which should be copies vs. symlinks based on: (a) how critical is it if missing, (b) how often does it change, (c) does it need to take effect immediately. [critical, post-separation]
