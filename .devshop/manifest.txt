# Shared files manifest — lists build tooling that lives in both repos.
#
# New projects start as a clone of the devshop repo (abra-kadabra), so these
# files are already present. After that, they're owned by the project and can
# diverge (e.g., .gitignore adds project-specific exclusions).
# sync-from-devshop.sh and sync-to-devshop.sh read this list to sync changes
# in either direction.
#
# NOT listed here:
# - Symlinked files (.devshop/, .claude/skills/, etc.) — always match devshop
# - Root-owned copies (settings.json, .dcg.toml) — copied on every container start
# - Project-only files (.env, settings.local.json, CLAUDE.project.md)
# See GUIDE.md § File Lifecycle for the full model.
