# Dev-shop manifest — defines what the devshop owns and what projects own.
#
# After the devshop separation (2026-04):
# - INJECTED files are symlinked into the project at container start by init-devshop.sh.
#   They are gitignored in the project repo. Edits go to abra-kadabra.
# - TEMPLATE files are copied into new projects by /ak-init. After that, they're
#   owned by the project and can diverge. sync-from-template.sh can pull updates.
# - Lines marked [private] are stripped from any public mirror.
