# File-lifecycle manifest — single source of truth for every project workspace path
# managed by the devshop. Each declared path carries an inline lifecycle annotation:
#
#   <path> [<tag>]
#
# Valid annotations (parser: kit/scripts/sync/lib/parse-manifest.sh):
#
#   [sync]          — manual bidirectional sync via sync/from-devshop.sh +
#                     sync/to-devshop.sh; project owns its copy and may diverge
#   [locked]        — root-owned copy, refreshed every container start by
#                     init-devshop.sh; project cannot edit (chown root + chmod 644)
#   [locked-dir]    — sticky-bit dir holding [locked] files (chmod 1755);
#                     prevents node from deleting locked leaves
#   [symlink]       — node-owned symlink to devshop, always matches devshop;
#                     auto-recovered by sync/create-devshop-symlinks.sh
#   [scaffold-once] — copied once at /ak-new-project create time; project owns
#                     thereafter and the template's version is no longer relevant
#
# Exclusions are written as `!path` and carry no annotation (e.g. `!.devcontainer/.env`
# excludes that file from a parent directory's [sync] rsync).
#
# See kit/docs/guide/architecture.md § File lifecycle for the model and the
# consumer scripts. The shared parser is kit/scripts/sync/lib/parse-manifest.sh.
