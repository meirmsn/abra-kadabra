# devshop CLAUDE.md classification

> Applies the 3-class taxonomy (per `kit/docs/guide/claude-md.md`) to `/devshop/CLAUDE.md` at HEAD on branch `feature/claude-md-architecture`. Drives the Wave 5 trim of the CLAUDE.md architecture migration.
>
> Goal: get devshop CLAUDE.md from ~44k → ~12-15k chars, symmetric in shape with the trimmed project CLAUDE.md (~6k chars). Trim opens up: (a) devshop sessions stop tripping the 40k Claude Code warning, (b) project sessions can have the slim devshop CLAUDE.md inlined via the `session-start.sh` hook without busting the truncation threshold.

Source: `/devshop/CLAUDE.md` (44k chars, ~13 major sections).

## Classifications used

Same as `home-os-claude-md-classification.md`:

- **Stay (verbatim).** Silent-failure devshop-development trap; load-bearing; no closer home. Keep in devshop CLAUDE.md.
- **Stay (condense + pointer).** Posture/recipe entry whose recipe lives in a guide doc; CLAUDE.md keeps a 1-2 sentence summary + pointer to the guide.
- **Lift to `kit/docs/guide/*.md`.** Recipe-heavy content that belongs at the canonical home; delete from CLAUDE.md after verifying the lift lands.
- **Lift to SKILL.md.** Skill-specific rule that belongs in the skill's own SKILL.md.
- **Delete (loud / historical).** Toolchain catches it loudly (test, hook, CI script) OR is historical context already covered by commits/docs.
