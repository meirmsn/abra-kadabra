# Findings register

Evidence base for the revamp. Every finding has an ID, a source, a confidence
mark, and the task(s) that resolve it. **Coverage rule:** every finding maps to
≥1 task ID or is explicitly marked `won't fix` / `obsolete by <task>` with a reason.
The plan review session checks this ([PROCESS.md](PROCESS.md#plan-review-session)).

Confidence: **V** = verified by reading code / running it / official docs in the
analysis session · **R** = reported by a review subagent, not independently
re-verified (verify before acting) · **?** = plausible, unconfirmed.

Paths are relative to the repo root. Line numbers are as of commit `e0f082a` (v1.38.0).

New findings discovered during the revamp are appended at the bottom under
**Discovered during revamp**, IDs `F-NEW-nn`, with "found during <task>".
