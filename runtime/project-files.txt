# Files the devshop places in a project (W10.4.7, L-49), read by scripts/project-files.py:
#   <owner> <devshop path> <project path>
# devshop: the project keeps an identical copy (executable bit included); session start reports
#          drift from the pinned version, and the upgrade skill (/devshop:upgrade) replaces it whole.
# seed:    a starting point the project adapts and owns; never overwritten or deleted, and the
#          upgrade shows only how the template changed.
# A fourth field `optional` (devshop files only) marks a copy a project has only when it needs it
# (the UI checks): init doesn't place it, check compares it only where it exists, the upgrade
# re-copies it where it exists. The project contract (runtime/project-contract.txt) lists every
# entry here with what it must do; tests/contract-check.test.sh holds the two together.
