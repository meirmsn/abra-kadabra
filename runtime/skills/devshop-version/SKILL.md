---
name: devshop-version
description: Which devshop version this session runs and how old its local copy is. Use when asked about the devshop version or the DEVSHOP line.
---

Quote this session's `DEVSHOP:` line from session start word for word: it names the devshop version,
where the pin came from (`.devshop-version` or the environment default) and the date and age of the
local devshop copy. If there is no such line, say that the devshop's SessionStart hook did not run in
this session.
